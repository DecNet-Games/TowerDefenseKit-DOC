# Frequently Asked Questions

**Is this a framework or a game?**
A complete game in a box: campaign, meta, art set — built on systems (grid, generation, director, economy) that are the product you extend.

**Can I add a tower without coding?**
Yes. Tower types are data files, validated on load. Malformed data is reported naming the tower.

**Do generated maps replace hand-made ones?**
No — both are supported. Generate for variety and shareable seeds; hand-author the maps you want to tune precisely.

**How are waves balanced?**
By the director: a difficulty curve plus per-wave budgets, with per-wave telemetry recorded so you can inspect pacing. The economy is separately proven winnable and losable by scripted runs.

**Is there multiplayer?**
No — single-player by deliberate scope. See [Limitations]({{ site.baseurl }}/docs/limitations/).

**Can I reskin the art?**
Yes. Presentation is style-only; swapping the art set changes no grid, tower, economy or wave behaviour.

support@decnetgames.com.
