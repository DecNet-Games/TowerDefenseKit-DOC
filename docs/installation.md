# Installation

The Tower Defense Complete Kit is a **commercial Unity Asset Store product**. Purchase and installation happen through the Asset Store — it is not available as a free download.

{: .important }
> Buyers install from the Unity Asset Store only.

---

## Requirements

- **Unity 2022.3 LTS or Unity 6 (6000.x)** — the full test suite is verified on both.
- Single-player only: no networking components, nothing to operate.
- The package ships with everything it needs: game systems, campaign content, art set, tests and documentation. No external asset dependency.

## Steps

1. Purchase the package on the Unity Asset Store.
2. In Unity, open the Package Manager and import it from **My Assets**.
3. Open the sample game and play a campaign map end to end — the fastest tour of every system.
4. Generate your first map from a seed (see the [Quick Start]({{ site.baseurl }}/docs/quick-start/)).

## What is in the package

| Part | Contents |
|---|---|
| Grid/path logic | Build grid, paths, pathfinding, placement rules |
| Towers | Tower types, targeting modes, upgrades, sell/refund — all data-driven |
| Economy | Kill/wave currency, guarded spending, lives system |
| Map generation | Seeded generation core + hand-authored map support |
| Encounter direction | Difficulty curves, budget composition, telemetry |
| Campaign & meta | Campaign of maps, progression, persistent upgrades/unlocks |
| Presentation | Game interface + one locked art set |
| Tests | The full verification suite, with a README on how to run it |
